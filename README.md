# AeroHarp

A gesture-controlled live music instrument. A webcam tracks hand movement, and hand position and shape become real-time control signals for [Magenta RealTime 2](https://github.com/magenta/magenta-realtime), an open source live music model, so you can "play" AI-generated music with your hands instead of a keyboard.

CS 352 Final Project, Northwestern University.

## What it does

Most AI music tools work by typing a prompt and waiting for a finished clip. AeroHarp tries to make it feel like playing an instrument instead: a webcam captures your hand, [MediaPipe](https://developers.google.com/mediapipe) tracks its landmarks, a classifier turns that into gesture and motion data, and that data controls Magenta RealTime 2 to generate music live in response.

Hand shape (fist, open palm, peace sign, point) triggers a musical style. Hand motion (openness, height) maps to continuous control values like intensity and pitch. Because Magenta RealTime 2's real-time streaming mode requires Apple Silicon hardware, AeroHarp runs offline: gestures are recorded first, then processed through the pipeline to generate the corresponding audio, rather than responding live.

## Repo structure

```
gesture_capture/
  record.py             records labeled webcam gesture clips to data/gestures/<gesture>/*.avi
  record_freeform.py    records one longer continuous clip for testing multi-gesture sequences
  extract_landmarks.py  runs MediaPipe on recorded clips, writes data/landmarks.csv
                         (columns: gesture, clip_id, 21 landmarks x/y/z)

classifier/
  train_classifier.py   trains a RandomForestClassifier on landmarks.csv, splits train/test
                         by clip_id (not by frame) so held-out clips are never partially seen
  baseline.py            a deliberately simple region-based pixel-motion classifier, used to
                         confirm the real classifier is actually learning something useful
  model.pkl              the trained classifier (generated by train_classifier.py)

control_mapping/
  map_to_mrt2.py         runs a gesture video through MediaPipe + model.pkl, applies temporal
                         smoothing to the frame-by-frame predictions, and outputs a
                         control_sequence.json (per-frame gesture, style_prompt, pitch_midi,
                         intensity)

mrt2_runner/
  generate.py             reads a control_sequence.json, groups it into style segments, and
                         calls Magenta RealTime 2 to generate audio for each segment, chaining
                         model state between segments for smoother transitions. Runs on a
                         cloud GPU (Colab), since MRT2 needs hardware this offline setup
                         doesn't have.
```

## Pipeline

```
Webcam -> MediaPipe -> Gesture classifier -> Control mapping -> Magenta RealTime 2
          (hand           (built here)         (built here)      (offline audio
          tracking)                                               generation)
```

1. `record.py` collects labeled gesture clips (fist, open_palm, peace_sign, point).
2. `extract_landmarks.py` runs MediaPipe on every clip and saves the 21 hand landmark coordinates per frame.
3. `train_classifier.py` trains a classifier on those landmarks; `baseline.py` provides a naive comparison point.
4. `map_to_mrt2.py` runs the trained classifier on a new gesture video, smooths the frame-by-frame predictions, and maps gesture/motion into a style prompt plus MIDI-style pitch and intensity values.
5. `generate.py` feeds that control sequence into Magenta RealTime 2 to generate the final audio.

## Results

The trained classifier reached 100% accuracy on held-out test clips, compared to 62.5% for the pixel-motion baseline. It specifically resolved the baseline's main weakness: confusing two visually similar closed-hand gestures that a pixel-motion approach can't tell apart, but real hand-shape landmarks can.

Running real recorded gestures through the full pipeline confirmed the system correctly switches musical style as the detected gesture changes. The classifier is noticeably more reliable on held, static poses than during active hand transitions, since training data only contained static gesture clips. That's a clear direction for future data collection.

Pitch and intensity are currently folded into the style prompt as descriptive modifiers (for example, "energetic, high-pitched") rather than passed to Magenta RealTime 2 as raw MIDI-style control values. MRT2's native note conditioning is token-based with no public encoder in the installed package version, so this was a deliberate simplification rather than an oversight.

## Setup

Requires Python 3, `opencv-python`, `mediapipe`, and `scikit-learn` for the local pipeline (dataset recording through control-sequence generation). Magenta RealTime 2 itself needs a GPU; this project runs it separately in Google Colab using the JAX backend, uploading the generated `control_sequence.json` and running `mrt2_runner/generate.py` there.
